챗GPT용 오프라인 업무자료 검색기 만들기 프롬프트 (최종본)
==================================================
아래 텍스트를 복사해서 챗GPT 대화창에 그대로 붙여넣기 하세요!

[복사할 내용 시작] -------------------------------
인터넷이 연결되지 않은 내 컴퓨터(오프라인)에서도 
안전하게 업무 자료를 검색할 수 있는 "업무자료 검색기"를 만들어주세요.

HTML, CSS, JavaScript 코드를 모두 합쳐서 단 1개의 HTML 파일 코드로 짜주세요.

[필수 기능 및 요구사항]
1. 디자인
- 경찰이나 관공서 느낌이 나는 깔끔하고 예쁜 파란색 톤으로 만들어주세요.
- 모바일과 컴퓨터에서 모두 예쁘게 보이게 해주세요 (반응형 디자인).
- 파일 추가 영역과 검색 영역을 카드로 나누어서 깔끔하게 구분해주세요.

2. 지원하는 파일 (중요: HWPX 지원)
- 텍스트 추출이 가능한 .csv, .txt, .md 파일과 **.hwpx 파일**을 업로드할 수 있게 해주세요.
- hwpx 파일을 읽기 위해 jszip 라이브러리를 CDN(https://cdnjs.cloudflare.com/ajax/libs/jszip/3.10.1/jszip.min.js)으로 가져와서 사용해 주세요. xml 내부의 hp:t 태그에서 텍스트를 추출하는 로직을 반드시 포함해 주세요.
- 만약 .hwp나 .pdf 같은 다른 파일을 올리면 "지원하지 않는 파일입니다"라는 경고창을 띄워주세요. (조용히 넘어가면 안 됩니다!)

3. 한글 깨짐 방지
- 텍스트 파일을 읽을 때 글자가 깨지지 않도록, UTF-8로 먼저 읽고 실패하면 EUC-KR로 다시 읽어오는 똑똑한 기능을 넣어주세요.

4. 데이터 저장과 검색 (가장 중요: 영구 저장)
- 올린 파일은 브라우저의 내부 저장소(IndexedDB)에 안전하게 저장해서, 창을 껐다 켜거나 컴퓨터를 재부팅해도 파일이 절대로 지워지지 않고 남아있게 해주세요.
- localStorage는 용량 제한이 있으니 반드시 **IndexedDB**를 사용해 주세요.
- 검색창에 단어를 치면 딜레이 없이 검색되게 해주고, 검색된 글자는 노란색으로 칠해주세요.
- 검색 결과가 너무 많으면 브라우저가 멈출 수 있으니, 상위 100개까지만 보여지게 제한해주세요.

5. 오류 방지
- IndexedDB 저장이나 HWPX 파일 분석 시 오류가 발생하면 화면이 멈추지 않고, 사용자에게 알림창(alert)으로 원인을 친절하게 알려주도록 예외 처리(try-catch)를 꼼꼼하게 해주세요.
